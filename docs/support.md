# Myan Support

## Requirements

- macOS 14 or later
- Apple Silicon Mac for the current beta
- Myan - Download Manager installed in `/Applications`

## Browser Setup

Open Myan once after installing it. This installs the local browser connection
used by Chrome and Arc.

For Safari, install and open Myan Safari Extension, then enable it under
**Safari > Settings > Extensions**.

## Get Help

Report a problem on the public support tracker:

https://github.com/thelapyae/myan-download-manager-releases/issues

Do not include private download URLs, authentication tokens, cookies, or other
sensitive information in an issue.
