# Myan v0.1.0 Beta

Initial public beta of Myan - Download Manager.

## Included

- Multipart HTTP range downloads
- Automatic single-connection fallback
- Pause, resume, retry, cancel, and delete controls
- Download speed, progress, file size, and ETA
- Chrome and Arc automatic download capture
- Safari direct-link capture
- Browser context-menu download handoff
- Developer ID signed macOS applications

## Requirements

- macOS 14 or later
- Apple Silicon Mac

## Important

This beta is signed but not notarized. macOS may require **Open Anyway** from
**System Settings > Privacy & Security** on first launch.
